# Prediccion-Calidad-del-Aire
Repositorio académico del proyecto de investigación sobre predicción de la calidad del aire mediante la integración de datos de contaminantes atmosféricos (PM10 y PM2.5) y variables meteorológicas, análisis de series temporales y aplicación de técnicas de aprendizaje automático para la imputación de datos faltantes y el modelado predictivo.
